### 1. New module `src/lib/startSectionSettings.ts` (+ unit tests)
Follows the repo's established timerSettings.ts pattern (NIP-78 kind 30078 per-account sync + localStorage) with a cookie mirror so the server can redirect without a page flash:
- `type StartSection = 'feed' | 'explore' | 'recipes'`; `DEFAULT = 'feed'`; path map: feed→`/community`, explore→`/explore`, recipes→`/recipes`
- `startSection` writable initialized from localStorage at module load (`typeof localStorage` guard, foodFilterSettings-style, for vitest importability); `parseStartSection()` validator; `startSectionTarget()` sync helper for `goto()` call sites
- Cookie `zapcooking_start_section` (Path=/, 1y, SameSite=Lax) written on every save and on relay-load
- `loadStartSectionSettings()` (localStorage immediate → newest NIP-78 event `#d=['start-section']` → validate → set + mirror) and `saveStartSection()` (store + localStorage + cookie instantly, NIP-78 publish fire-and-forget)
- Tests: `src/lib/startSectionSettings.test.ts` (parse/validation, path mapping, storage round-trip)
